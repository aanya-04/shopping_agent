 🛒 Shopping Agent

An AI-powered shopping assistant built using **LangChain, LangGraph, Groq, and Streamlit**.

The agent can understand user shopping requests, work with product information, and use tools to provide product-related assistance through a simple Streamlit interface.

🚀 Features

- 🤖 AI-powered shopping assistant
- 🔧 Tool calling with LangChain/LangGraph
- 🛍️ Product information and recommendations
- 🖼️ Product image description
- 💬 Conversational interaction
- 🌐 Streamlit web interface
- 🧠 Agent-based decision making

 🛠️ Technologies Used

- Python
- LangChain
- LangGraph
- Groq
- Streamlit
- Python-dotenv
